# AERIS Context Folder

Drop any `.md` files here to give the AI assistant awareness of project context.

## How it works
- Any `.md` file you place in this folder will be read by the assistant at the start of relevant tasks.
- Use it for: architecture decisions, module overviews, coding conventions, known issues, roadmap notes, etc.

## Suggested Files
- `architecture.md` — High-level system design
- `modules.md` — Description of each module/feature
- `conventions.md` — Coding style and patterns used in AERIS
- `roadmap.md` — Planned features and priorities
- `known_issues.md` — Bugs or limitations to be aware of
